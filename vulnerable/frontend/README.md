# Vulnerable Frontend (Vue 3 + Vite)

## 启动方式
```bash
cd vulnerable/frontend
npm install
npm run dev
```

默认地址：`http://127.0.0.1:5173`

## 管理系统说明
- 系统为后台管理形态：左侧菜单 + 顶栏 + 内容区
- 左侧菜单固定，右侧内容区独立滚动
- 未登录不可访问业务页面，统一跳转 `/login`
- 页面以表格为主，新增/编辑/处理使用 Modal 弹窗
- 列表页统一分页（页码/每页条数）
- 登录后按角色进入不同端：
  - `admin` -> 管理后台（`/admin/...`）
  - `resident` -> 居民端（`/resident/...`）

## 主要模块
- 仪表盘
- 仪表盘 ECharts 图表（趋势/状态分布/事项排行）
- 用户角色管理（管理员）
- 事项管理
- 申请管理
- 受理审批
- 公告管理（管理员可新增/编辑/删除）
- 消息通知
- 评价反馈
- 顶部登录用户信息展示、个人资料修改、密码修改
- 顶部头像/姓名下拉菜单：个人信息、修改密码、退出登录
- 前端路由与按钮级权限控制（查看/编辑/提交/审批）

请先启动后端接口：`http://127.0.0.1:8000`
